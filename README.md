# 🧩 CPU 五層ビュー

16bit の小さな CPU を **C → アセンブリ → 機械語 → 論理回路 → チューリングマシン** の 5 層で同時に動かし、**動作フローチャート**と**数学ビュー**を加えた 7 つのビューで見るビジュアライザです。`index.html` を開くだけで動きます（ビルド不要）。

- 5 層はそれぞれ**独立した定義**で同じプログラムを実行し、1 命令ごとにレジスタ・RAM・フラグ C・LR・PC・停止状態を突き合わせます（右上の「一致 ✓ 5/5」）
  - C: 構文木を C の意味論で解釈 / ASM: ニーモニックの意味で解釈 / 機械語: 16bit 語をオペコード表で解読
  - 回路: ゲート 1247 個のネットリスト + ROM 256 語 + RAM 64 語の単一サイクル CPU
  - TM: 状態 1486 個・遷移 7657 本の δ だけでテープ（= 機械語 + レジスタ + RAM + C）を書き換える。重いときは上の「TM」チェックで省略可（自動でも省略）
- 命令: `INC DEC ADD SUB MOV SHR LDI LD ST JZ JNZ JC JNC JMP CALL RET HALT`
- C の部分集合: `unsigned int`（16bit）変数 8 個まで（作業用レジスタ分を除く）、配列（RAM）、`+ - * / % >> <<`（`* / %` はシフト加算・筆算割り算のループに展開）、比較、`while` `for` `if … else` `break`、引数なしの関数（葉関数のみ）
- ビュー: 俯瞰 / 詳細 / 全体（高負荷）。TM のロジック解説（擬似コード ⇔ 状態、なぜこの遷移か）、フローチャート、**数学ビュー**（ニュートン法の接線、オイラー法と厳密解の比較、互除法の正方形分割、黄金比、ソートの棒、篩の表 …）
- どの動きもホバーで「どの定義で動いているか」が見られます。`定義トレース`（T キー）と `定義一覧`（D キー）でも確認できます

サンプル: ニュートン法（√2）、オイラー法（指数減衰・ロジスティック・自由落下）、互除法、フィボナッチと黄金比、コラッツ（関数）、素因数分解・エラトステネスの篩・バブルソート（配列）など。

| キー | 操作 |
|---|---|
| Space | 実行 / 一時停止 |
| → / Shift+→ | 1 命令 / TM 1 ステップ |
| E | 最後まで一気に |
| R | リセット |
| 1 / 2 / 3 | 俯瞰 / 詳細 / 全体 |

テスト: `node test.js`（全サンプルとランダムなプログラム・掛け算割り算を同期実行し、毎命令の一致と結果を確認。`--tm-all` で全サンプル TM 込み）
